## 2️⃣ 配置弹窗（两层JSON结构）

### 数据结构说明

```json
{
  "回复设置": {
    "reply_template": "你好，我现在不方便回复，稍后联系你。",
    "delay_time": 5,
    "enable_keyword": true
  },
  "高级选项": {
    "auto_at_reply": false,
    "quiet_hours_start": "22:00",
    "quiet_hours_end": "08:00"
  },
  "通知设置": {
    "enable_sound": true,
    "enable_vibrate": false,
    "notification_priority": "high"
  }
}
```

**结构说明**：
- **第一层key**（如：回复设置、高级选项、通知设置）→ 左侧配置分类列表
- **第二层key-value** → 右侧配置编辑器中的具体配置项

## 配置项类型支持

| 类型 | 说明 | 示例 |
|------|------|------|
| `string` / `text` | 文本输入框 | reply_template |
| `number` / `int` | 数字输入框/滑块 | delay_time |
| `boolean` | 开关按钮 | enable_keyword |
| `select` / `enum` | 下拉选择框 | notification_priority |
| `time` | 时间选择器 | quiet_hours_start |

## 数据结构转换说明

### 后端存储格式（JSON字段）
```json
{
  "回复设置": {
    "reply_template": "你好，我现在不方便回复，稍后联系你。",
    "delay_time": 5,
    "enable_keyword": true
  },
  "高级选项": {
    "auto_at_reply": false,
    "quiet_hours_start": "22:00",
    "quiet_hours_end": "08:00"
  }
}
```

### 前端展示格式
```javascript
// 左侧分类列表
[
  { "key": "回复设置", "label": "回复设置", "selected": true },
  { "key": "高级选项", "label": "高级选项", "selected": false }
]

// 右侧配置项（根据选中的分类动态生成）
[
  { 
    "key": "reply_template", 
    "label": "reply_template", 
    "type": "text", 
    "value": "你好，我现在不方便回复，稍后联系你。" 
  },
  { 
    "key": "delay_time", 
    "label": "delay_time", 
    "type": "number", 
    "value": 5,
    "min": 1,
    "max": 60,
    "unit": "秒"
  },
  { 
    "key": "enable_keyword", 
    "label": "enable_keyword", 
    "type": "boolean", 
    "value": true 
  }
]
```

## API 设计

### 获取技能配置
```
GET /api/skills/config/{skill_name}

Response:
{
  "code": 2000,
  "data": {
    // 直接返回数据表中的JSON字段内容
    "回复设置": {
      "reply_template": "你好...",
      "delay_time": 5,
      "enable_keyword": true
    },
    "高级选项": {
      "auto_at_reply": false,
      "quiet_hours_start": "22:00",
      "quiet_hours_end": "08:00"
    }
  }
}
```

### 保存技能配置（单个字段自动保存）
```
POST /api/skills/config/{skill_name}

Body:
{
  // 完整JSON结构，只修改变化的字段
  "回复设置": {
    "reply_template": "你好，我现在不方便回复，稍后联系你。",
    "delay_time": 5,
    "enable_keyword": true
  },
  "高级选项": {
    "auto_at_reply": false,
    "quiet_hours_start": "22:00",
    "quiet_hours_end": "08:00"
  }
}

// 或者只传修改的部分（后端合并）
{
  "回复设置": {
    "delay_time": 10  // 只修改了这个字段
  }
}
```

## 交互说明

1. **打开弹窗**：点击技能卡片上的 ⚙️ 按钮
2. **切换分类**：点击左侧分类列表，右侧显示该分类下的所有配置项
3. **修改配置**：在右侧编辑器中修改值，触发 `onchange` 事件
4. **自动保存**：`onchange` 后自动调用保存API，显示「✓ 已自动保存」
5. **关闭弹窗**：点击右上角 × 或点击弹窗外部区域
